# 设计原理与研究方向

[← 返回 README](../README.zh.md) ｜ [English](DESIGN.md)

实现背后的想法、约束它的实测事实，以及正在攻关的开放问题。

## 研究方向

促使当前工作的实测事实：

> **独立随机化的** `param` 段会**破坏**权重几何：
> `corr(hash 的 Hamming 距离, 权重余弦相似度) = +0.0019`（即完全无关）。
> 只用语义 `mask` 时为 `−0.9885`（近乎完美单调）。

解释：同一个 `k` 维 sign 向量**无法**同时承载**几何**与**独立自由度**。

正在探索的方向是 **码作为索引**：

```
码（hash）    →  索引   →  几何由寻址天然保证（局部性）
信息码        →  内容   →  可以承载任何东西，无需遵守几何约束
```

以及 **MoE 式稀疏激活**：让「编辑某个 token 的信息码」只影响它真正激活的那 `k'` 个基矩阵
—— 即**稀疏写**，而不只是稀疏读。

**开放问题**（作者认为「优雅解」就在这里）：

> 能否学出一组共享基矩阵，使得「编辑任意一个码」对其它所有 token 输出的影响**有可界定的上界**？
>
> 若能，这将是稳定性–可塑性困境在**参数化层面**的表述 ——
> 而局部性正是生物突触（STDP）无需全局梯度即可持续学习的机制。

## 什么算做完 —— 验收标准

本项目的北极星指标是**成本调整后的持平**，而不是超越：

> 目标不是打败现有方法，而是证明 per-token 权重码**并不更差** ——
> 同时更省、可位级精确回滚、还兼作检索键。

这与 [BitNet b1.58](https://arxiv.org/abs/2402.17764) 的定位方式一致：
先追平质量，再把成本打下去。**持平在附带成本下降时才是有价值的结论；
同等成本下的持平只是「另一种实现」，不构成贡献。**

#### 自学习可行性 —— 写成可测的形式

「自学习可行」必须是一张清单，不能是一种感觉。这里的声明是**可行性**，
拆成四条可验证的条件：

| # | 条件 | 状态 | 已有证据 / 如何测量 |
|---|---|---|---|
| ① | 新增领域后，旧领域性能不下降 | ✅ **已测** | 每域码表：遗忘 **0.0000**，回滚位级精确 |
| ② | 质量持平的前提下，适配成本低于 LoRA | ⬜ 待做 | 250 KB/域 vs LoRA r=16 的 500 KB —— 成本已知，**质量是否持平未知** |
| ③ | 可按 token 粒度新增/修改，且不需重训主干 | ⬜ 待做 | 稀疏写已实现（爆炸半径 `k'/k`，0 个其他 token 受影响），但还没有端到端测试 |
| ④ | 在真实任务上成立，而不只是 5 个合成域 | ⬜ 待做 | ① 的结果来自 3,109 词 / 5 个合成域 |

**项目结束时，每一行要么打勾、要么打叉，并附上测量结果。** 不靠印象定论。

#### 决定 ② 的那个对比

质量持平是前提，所以必须先测。**在质量持平的前提下**，比较：

| 维度 | 本项目 | LoRA r=16 |
|---|---|---|
| 每域存储 | 250 KB | 500 KB |
| 回滚粒度 | **位级精确** | 文件级替换 |
| 码兼作检索键 | **是**（HSH-64，一次 `popcnt`） | 否 |
| 质量 | **待测** | 基线 |

若质量持平、其余三栏本项目占优，则结论是：

> **一种更省、可精确回滚、并同时充当检索索引的 per-domain 适配方案。**

这个声明经得起追问，因为它是定量的。而「我们解决了灾难性遗忘」这种声明站不住 ——
这里的零遗忘来自**物理隔离**（与 PackNet / HAT / PNN 同一机制），是**用容量换的**。
